# foonshell

A desktop shell for Hyprland built with [Quickshell](https://quickshell.outfoxxed.me/), including a status bar, notification daemon, logout/power overlay, and volume/microphone OSD.

## Features

- **Status Bar**:
  - **Workspaces**: Per-monitor Hyprland workspaces with deduplicated application icons and scroll switching.
  - **Window Title**: Active window title for the focused monitor.
  - **Clock & Calendar**: Interactive month calendar popup with multi-feed iCal event synchronization and offline caching.
  - **Media**: Now-playing cover art, artist/title, and popup media controls via MPRIS.
  - **System Tray**: StatusNotifierItem tray with context menus.
  - **Status Pill**:
    - **Bluetooth**: Device connection status, battery levels, and scan/pair/connect popup.
    - **Network**: Wired and Wi-Fi status, signal strength, and network switcher popup.
    - **Audio**: PipeWire output/input volume, device form-factor icons, mute toggle, and device picker popup.
    - **Standing Desk**: Live height and preset controls when the `desk` CLI is available.
    - **Battery**: Laptop battery status, remaining time, power draw, health, charge cycles, and charge limit.
- **Notifications**: Built-in desktop notification server with actions, markup, and image support.
- **Logout / Power Menu**: Full-screen overlay with keyboard navigation, shortcut keys, and IPC triggers (`lock`, `logout`, `suspend`, `reboot`, `shutdown`).
- **Volume & Microphone OSD**: On-screen display for output/input volume, mute state, and default device changes.
- **Live Configuration & Theming**: Watches `~/.config/foonshell/` for changes to settings and calendar feeds, and `~/.local/state/foonshell/` for Material Design 3 colors (e.g. generated by `matugen`) without restarting.

## Requirements

- [Quickshell](https://quickshell.outfoxxed.me/)
- [Hyprland](https://hyprland.org/)
- PipeWire & `pactl` (`libpulse`) for audio device detection
- A Nerd Font (defaults to `MonaspiceNe NFP`)
- Optional:
  - `python3`, `python-icalendar`, and `python-recurring-ical-events` (for iCal calendar sync)
  - `matugen` (for dynamic wallpaper color generation)
  - `desk` CLI (for standing desk controls)

## Installation

Clone the repository into your Quickshell configuration directory:

```sh
git clone https://github.com/foonly/foonshell.git ~/.config/quickshell/foonshell
```

Run with Quickshell:

```sh
qs -c foonshell
```

## Configuration

User configuration lives in `~/.config/foonshell/` (or `$XDG_CONFIG_HOME/foonshell/`). All files and keys are optional and hot-reloaded on change.

### `config.json`

Copy `config.example.json` to `~/.config/foonshell/config.json` to customize fonts, bar dimensions, clock formats, and widget layout:

```json
{
    "font": "MonaspiceNe NFP",
    "fontSize": 13,
    "iconSize": 15,
    "barHeight": 34,
    "gap": 6,
    "radius": 10,
    "pillPadding": 10,
    "clock": {
        "dateFormat": "ddd d MMM",
        "timeFormat": "HH:mm"
    },
    "bar": {
        "left": ["workspaces", "windowTitle"],
        "center": ["clock"],
        "right": ["media", "tray", "status"],
        "status": ["bluetooth", "network", "audio", "desk", "battery"]
    }
}
```

Available widgets: `workspaces`, `windowTitle`, `clock`, `media`, `tray`, `status`, `bluetooth`, `network`, `audio`, `desk`, `battery`.

### `calendars.json`

Copy `calendars.example.json` to `~/.config/foonshell/calendars.json` to configure iCal feeds for the calendar popup:

```json
{
    "calendars": [
        {
            "name": "Private",
            "url": "https://calendar.google.com/calendar/ical/.../basic.ics",
            "color": "#8ab4f8"
        }
    ]
}
```

Fetched events are cached in `~/.cache/foonshell/events.json`.

### `colors.json`

`~/.local/state/foonshell/colors.json` (`$XDG_STATE_HOME/foonshell/colors.json`) defines Material Design 3 color tokens (`background`, `surface`, `surface_container`, `surface_container_high`, `surface_container_highest`, `on_surface`, `on_surface_variant`, `outline`, `outline_variant`, `primary`, `on_primary`, `secondary`, `tertiary`, `error`). If omitted, `Theme.qml` uses built-in dark palette fallbacks.

## IPC Commands

Control the logout menu and volume OSD via Quickshell IPC:

```sh
# Logout / Power menu
qs ipc -c foonshell call logout toggle
qs ipc -c foonshell call logout open
qs ipc -c foonshell call logout close
qs ipc -c foonshell call logout lock

# Volume OSD
qs ipc -c foonshell call volume increase
qs ipc -c foonshell call volume decrease
qs ipc -c foonshell call volume toggleMute
qs ipc -c foonshell call volume toggleMicMute
```
